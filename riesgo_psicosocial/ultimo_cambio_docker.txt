## **CAMBIOS EN EL DOCKERFILE**

### **CAMBIO 1: Imagen Base (Línea 2)**

**ANTES:**
```dockerfile
FROM r-base:latest
```

**DESPUÉS:**
```dockerfile
FROM rocker/tidyverse:latest
```

**¿Qué cambió y por qué?**

| Aspecto | `r-base:latest` | `rocker/tidyverse:latest` |
|---------|---|---|
| **Tamaño** | ~500 MB | ~800 MB |
| **R instalado** | Sí | Sí |
| **Dependencias del sistema** | Mínimas | Muchas (dev tools, compiladores) |
| **Paquetes R preinstalados** | Ninguno | tidyverse, ggplot2, dplyr, readxl, stringr, etc. |
| **¿Compila officer y flextable?** | ❌ No | ✅ Sí |

**Por qué funcionó con `rocker/tidyverse`:**

```
r-base:latest
└─ Linux básico + R
    └─ Falta: compiladores C++, headers de XML, headers de Protobuf
    └─ officer necesita eso → FALLA

rocker/tidyverse:latest
└─ Linux + R + herramientas de compilación preinstaladas
    └─ Ya tiene: build-essential, libxml2-dev, libprotobuf-dev, etc.
    └─ officer compila correctamente → ÉXITO
```

### **CAMBIO 2: Instalación de Shiny (Línea 8)**

**ANTES:**
```dockerfile
# Instala dependencias del sistema necesarias para compilar librerías de R
RUN apt-get update && apt-get install -y \
    libcurl4-openssl-dev \
    libssl-dev \
    libxml2-dev \
    libpq-dev \
    libfontconfig1-dev \
    libuv1-dev \
    libfreetype6-dev \
    pkg-config \
    libprotobuf-dev \
    protobuf-compiler \
    unzip \
    && rm -rf /var/lib/apt/lists/*

# Instala Shiny primero (es lo más importante)
RUN R --slave -e 'install.packages("shiny", repos="https://cloud.r-project.org")'
```

**DESPUÉS:**
```dockerfile
# Instala Shiny y librerías adicionales necesarias
RUN R --slave -e 'install.packages(c("shiny", "pool", "scrypt"), repos="https://cloud.r-project.org")'
```

**¿Qué cambió?**

1. **Eliminé toda la instalación de dependencias del sistema** → Ya vienen en `rocker/tidyverse`
2. **Combiné Shiny + pool + scrypt en una sola línea** → Menos capas en la imagen, más eficiente
3. **Eliminé la instalación de librerías que ya vienen** → `rocker/tidyverse` ya tiene tidyverse, dplyr, readxl, stringr, magrittr

**Ahorro:**
- Antes: 17 líneas de instalación de dependencias
- Después: 1 línea (todo ya está en la imagen base)

## **CAMBIOS EN SCRIPTS R**

También cambiaste dos archivos para que usen `postgres` como host:

### **1. `R/utils_db.R` - Línea 15**

**ANTES:**
```r
host     = Sys.getenv("PG_HOST",     "/var/run/postgresql"),
```

**DESPUÉS:**
```r
host     = Sys.getenv("PG_HOST",     "postgres"),
```

**¿Por qué?** En Docker, el nombre del servicio es `postgres`, no el socket Unix `/var/run/postgresql`.

### **2. `conectar_bd.R` - Línea 37**

**ANTES:**
```r
host     = Sys.getenv("PG_HOST", "/var/run/postgresql"),
```

**DESPUÉS:**
```r

```

**¿Por qué?** Same reason - Docker networking usa nombres de servicios.
